# Abigail Ronald-Louw Attorneys — Independent Website Concept

## Setup
Static HTML, CSS and JavaScript. No build dependencies. Start a local preview from this folder using `python3 -m http.server 8000`, then visit http://localhost:8000.

## Deploy
Vercel preset: **Other**; root folder: `.`; output folder: `.`. Vercel CLI: `npx vercel --prod`.
Create a new public GitHub repo with `gh repo create abigail-ronald-louw-attorneys --public --source=. --remote=origin --push`.
